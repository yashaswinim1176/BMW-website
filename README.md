## 📌 Overview

**BMW 7 Series Competition — Disassembly Engineering Showcase** is an interactive, scroll-driven web application featuring a high-precision 80-frame exploded view disassembly sequence of the BMW 7 Series luxury sedan.

Built with an HTML5 `<canvas>` rendering engine, linear interpolation (`lerp`) frame scrubbing, and glassmorphism user interface components, this application allows users to deconstruct the vehicle layer-by-layer as they scroll.

---

## ✨ Key Features & Highlights

- 🚗 **3D Scroll Disassembly Engine**: Synchronizes document scroll position with an 80-frame image sequence, producing fluid frame transitions.
- 🎨 **Matte Black Studio Backdrop**: High-contrast dark mode aesthetic with canvas masking to ensure visual clarity.
- 📊 **Interactive Performance Bar**: Displays key engineering specifications (`536 HP`, `3.7s 0-100 km/h`, `4.4L V8`, `2.05 T`, `250 km/h`).
- 🎛️ **Scrub Bar & Phase Navigation**: Bottom range slider and side-navigation dots for direct frame scrubbing across disassembly phases:
  - **Phase 1 (0%–20%)**: Fully Assembled Vehicle
  - **Phase 2 (20%–40%)**: Carbon Core Structural Architecture
  - **Phase 3 (40%–60%)**: Executive Lounge Cabin Disassembly
  - **Phase 4 (60%–80%)**: M TwinPower Turbo Powertrain Explosion View
  - **Phase 5 (80%–100%)**: Adaptive 2-Axle Air Suspension & Chassis Technical View
- 📋 **Test Drive Registration**: Built-in test drive booking interface with input validation.

## 🛠️ Technical Stack & Architecture

| Component | Technology | Purpose |
| :--- | :--- | :--- |
| **Canvas Engine** | HTML5 `<canvas>` 2D Context | High-DPI hardware-accelerated image rendering |
| **Scroll Interpolation** | JavaScript (`requestAnimationFrame` + `lerp`) | Fluid frame scrubbing with inertia smoothing |
| **Styling & UI** | CSS3 (Flexbox/Grid + Glassmorphism) | Dark luxury automotive web UI |
| **Asset Pipeline** | UTF-8 Preloaded 80-Frame Sequence | Instant, zero-lag frame transitions |

## 🚀 How to Run Locally

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/yashaswinim1176/BMW-website.git
   cd BMW-website
   ```

2. **Launch Local HTTP Server:**
   ```bash
   python -m http.server 8080
   ```

3. **Open in Browser:**
   Navigate to `http://localhost:8080` in any modern web browser.
